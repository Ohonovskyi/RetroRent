**Чому немає секції «Відгуки».** У матеріалах проєкту немає реальних відгуків клієнтів, а в завданні сказано: *«Не вигадуй статистику, відгуки або характеристики, яких немає у вихідних матеріалах»*. Тому роль «соціального доказу» виконують блоки «Переваги» (КАСКО, перевірені авто) і «Як це працює» (прозорий процес). Щойно з'являться справжні відгуки, їх варто додати між «Як це працює» і «Відео».

## Етап 6. Pick Element і мікровзаємодії

**Обраний компонент — секція «Послуги».** Відступи: мобільний `py-16`, з `md:` — `md:py-20`. На мобільному відступи менші, десктоп не змінюється.

**Аналіз CTA.**
- «Бронювати» (хедер) — головний, темний `bg-navy`, видно на кожному екрані.
- «Обрати авто під подію» (Hero) — білий на темному фото, контраст високий.
- «Обрати авто» (CTA-секція) — білий на `bg-royal`, поруч другорядна обведена кнопка з телефоном. Так основна дія не конкурує з другорядною.
- Тексти кнопок говорять, що станеться: «Обрати авто», «Прокласти маршрут» (з `title` про нову вкладку).

**Мікровзаємодії (лише Tailwind).** `transition`, зміна кольору `hover:bg-royal` / `hover:bg-cream`, легка тінь `hover:shadow-lg` / `hover:shadow-xl`, помітний фокус `focus-visible:ring-3 focus-visible:ring-brand-orange`. Розмір кнопок при наведенні не змінюється.

## Етап 7. Медіа

- **YouTube:** `<figure>` → `.embed` → `<iframe title="…" loading="lazy" allowfullscreen>`, домен `youtube-nocookie.com` (без cookie до натискання).
- **Google Maps:** iframe у секції контактів, обгорнутий у `<figure>`, має `title`, `loading="lazy"`, `referrerpolicy`.
- **CSS (`css/style.css`):** один клас `.embed` для обох iframe (принцип DRY). Розміри, радіус і тінь — змінні в `:root`: `--embed-max-width`, `--embed-radius`, `--embed-shadow`, `--embed-map-min-height`.

## Етап 8. Фінальний аудит

**Семантика.**
- `header`, `nav`, `main`, `section` (з `aria-labelledby`), `article` (картки), `footer`, `address` (контакти), `ol` (кроки), `details/summary` (FAQ), `figure` (медіа).
- На кожній сторінці рівно один `h1`, далі `h2` → `h3`.
- Перевірено скриптом: усі теги закриті, `id` не повторюються, у всіх `img` є `alt`, у всіх `iframe` є `title`.

**Tailwind-аудит.**
- ⚠️ Довгі однакові набори класів кнопок повторюються. Без збірки це неминуче, у продакшені винесли б у компонент чи `@apply`.
- ⚠️ Є arbitrary values під пікселі макета: `text-[17px]`, `h-[61px]`, `md:w-[149px]`.
- ✅ Конфліктних класів у станах календаря немає: JS підставляє лише один набір.

**Доступність (WCAG 2.2 AA).**
- Контраст:
  - `#c4c6cf` на `#0d1526` ≈ 10:1;
  - `#6b7080` на білому ≈ 4.9:1;
  - білий на `#0d2a7a` ≈ 13:1.
- Фокус видно на всіх посиланнях і кнопках (помаранчева рамка).
- FAQ відкривається з клавіатури (Enter / Space).
- ⚠️ Опис під відео є, але до вставлення справжнього ID плеєр показує помилку YouTube.

## Етап 9. DevTools і Lighthouse

**Console.** Помилок JavaScript немає. Є одне очікуване попередження: *«cdn.tailwindcss.com should not be used in production»*.

**Очікувані зауваження Lighthouse:**

| Важливість | Проблема | Рішення |
|---|---|---|
| Середня | Performance: Tailwind CDN компілює CSS у браузері (блокує рендер) | У продакшені — Tailwind CLI, готовий мінімізований CSS |
| Середня | Великі JPG (до 1920px) | Стиснути / конвертувати у WebP, додати `srcset` |
| Незначна | Сторонні iframe (YouTube, Google Maps) впливають на швидкість | Уже є `loading="lazy"`; можна замінити відео на «фасад» з прев'ю |
| Незначна | Best Practices: cookies сторонніх сервісів | Використано `youtube-nocookie.com` |

Фактичні цифри Performance / Accessibility / Best Practices / SEO вставте зі свого запуску Lighthouse.
