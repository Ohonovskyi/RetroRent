## Етап 2. Класичний CSS vs utility-first

| Клас Tailwind | CSS, який він генерує | Значення |
|---|---|---|
| `bg-blue-600` | `background-color: #2563eb` | фон, синій відтінок 600 зі стандартної палітри |
| `text-white` | `color: #fff` | колір тексту |
| `px-6` | `padding-left: 1.5rem; padding-right: 1.5rem` | 24px по горизонталі (1 одиниця = 0.25rem = 4px) |
| `py-3` | `padding-top: .75rem; padding-bottom: .75rem` | 12px по вертикалі |
| `rounded-lg` | `border-radius: .5rem` | заокруглення 8px |

**Різниця підходів.** У класичному CSS ми придумуємо назву класу (`.primary-button`) і пишемо стилі в окремому файлі. У Tailwind кожен клас робить одну дію, а стилі збираються прямо в HTML. Плюси: не треба вигадувати назви, немає «мертвого» CSS, адаптив і стани пишуться поруч (`md:`, `hover:`). Мінуси: довгі рядки класів і повторення однакових наборів на різних сторінках.

## Етап 12. Аналіз коду, згенерованого ШІ

### Кнопка (Button)
- ✅ **Правильно:** усі стани з референсу Figma зроблені варіантами Tailwind (`hover:`, `active:`, `focus-visible:`, `disabled:`), висота ≥ 44px (`h-11`, `h-12`), на кнопках зі зміною тексту є `aria-label`.
- ⚠️ **Сумнівно:** довгий однаковий набір класів повторюється в 9 HTML-файлах. Без збірки немає компонентів, тож щоб змінити кнопку, треба редагувати всі сторінки.
- 🤖 **ШІ додав сам:** ефект натискання `active:scale-98` (довелося розширити тему значенням `scale.98`) і налаштування `hoverOnlyWhenSupported`, щоб hover не «залипав» на телефоні.

### Header
- ✅ **Правильно:** патерн `md:hidden` (кнопка «Меню») + `hidden md:flex` (пункти меню), `aria-expanded` / `aria-controls`, семантичні `<header>` і `<nav>`.
- ⚠️ **Сумнівно:** є arbitrary values (`md:w-[149px]`, `md:w-[88px]`, `min-w-[200px]`) — точні пікселі з макета замість стандартної шкали.
- 🤖 **ШІ додав сам:** «липкий» хедер (`sticky top-0`). Також ШІ залишив текстову кнопку «Меню» зі стрілкою замість іконки-гамбургера, бо так у дизайні з ЛР №4/5.

### Картка (Card)
- ✅ **Правильно:** `<article>` + заголовок, `alt` і `loading="lazy"` у фото, `aspect-*` + `object-cover` замість фіксованої висоти, немає фіксованої ширини.
- ⚠️ **Сумнівно:** `text-[17px]`, `h-[61px]`, `aspect-[16/11]` — підгонка під пікселі макета. Два варіанти картки (головна / каталог) мають майже однакову розмітку.
- 🤖 **ШІ додав сам:** підйом картки при наведенні (`hover:-translate-y-1 hover:shadow-xl`) — у макеті цього не було.

### Сітка карток (Grid)
- ✅ **Правильно:** `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6`, картки розтягуються на ширину колонки.
- ⚠️ **Сумнівно:** на головній сітка ще й обмежена `max-w-sm sm:max-w-2xl lg:max-w-5xl` і має інший `gap`, ніж у каталозі, тобто поводиться не так само.
- 🤖 **ШІ додав сам:** `max-w-sm` на мобільному, щоб картка не розтягувалась на весь планшет в одну колонку.

### Footer
- ✅ **Правильно:** `grid-cols-1 md:grid-cols-2 lg:grid-cols-4`, заголовки колонок замінені з `<h4>` на `<h2>` (правильна ієрархія), `focus-visible:ring` на посиланнях, контраст `#c4c6cf` на `#0d1526` ≈ 10:1.
- ⚠️ **Сумнівно:** `lg:min-h-[258px]`, `max-w-[260px]`; великий текст «© 2026 RetroRent» вміщається в колонку лише на `text-2xl` (довелося зменшити з `xl:text-3xl` до `2xl:text-3xl`).
- 🤖 **ШІ додав сам:** вирівнювання по центру на мобільному (`text-center md:text-left`).

## Етап 14. Дизайн-система → Tailwind

| Токен з ЛР №4 | Значення | У Tailwind |
|---|---|---|
| Primary (темно-синій) | `#0d1526` | `bg-navy` (тема) |
| Secondary / hover | `#0d2a7a` | `bg-royal` (тема) |
| Фон картки | `#faf7f2` | `bg-cream` (тема) |
| Ціна | `#0a9a0a` | `text-brand-green` (тема) |
| Другорядний текст | `#6b7080` | `text-gray-500` (стандартний, майже збігається) |
| Шрифт заголовків | Nunito | `font-head` (тема) |
| Шрифт тексту | Nunito Sans | `font-sans` (тема) |
| Радіус кнопки | 6px | `rounded-md` |
| Радіус картки | 12px | `rounded-xl` |
| Тінь картки | `0 8px 24px rgba(13,21,38,.25)` | `shadow-card` (тема) |

Тема задана в `js/tailwind.config.js` (для CDN-версії Tailwind тема пишеться в JS-об'єкті `tailwind.config`).

### Розбір старого CSS з ЛР №5
1. **Повністю замінено Tailwind:** reset (Preflight), `.container`, header, footer, картки, теги, каталог, «Про нас», сітка сторінки авто, поле дати, верстка модалки, кольори/шрифти (через тему).
2. **Частково замінено:** кнопки (стани через варіанти, але `.is-pressed` / `.is-loading` у CSS), календар (класи генерує JS, тому додано `safelist` у конфіг), показ модалки (довелося використати arbitrary variant `[&.is-visible]:opacity-100`).
3. **Залишено у `css/style.css`:**
   - `[hidden] { display: none !important }` — інакше `.flex` перебиває атрибут `hidden`;
   - фон Hero (`url()` до картинки);
   - плейсхолдер фото через `::after { content: … }`;
   - спінер завантаження (`@keyframes`);
   - стан `.is-pressed`, який вмикає JS.

## Етап 15. Брейкпоінти (перевірено на 320 / 768 / 1280px)

- На 320px і 768px жодна сторінка не має горизонтального скролу.
- Усі кнопки та фільтри мають висоту ≥ 44px.
- Кнопка «Меню» з'являється до 768px і зникає з `md:`.
