# RetroRent — фронтенд

Статичний сайт оренди ретро-автомобілів: HTML + CSS + трохи чистого JavaScript (без фреймворків і збірки).

## Як запустити

Достатньо відкрити `index.html` у браузері (подвійний клік).

Зручніше — через VS Code з розширенням **Live Server** (ПКМ по `index.html` → *Open with Live Server*), тоді сторінка сама оновлюється після збереження.

## Зображення — куди що класти

Поки файлу немає, на його місці показується сірий блок **IMAGE PLACEHOLDER**. Щойно покладете файл з потрібною назвою — він з’явиться сам. У HTML біля кожного фото є коментар `<!-- ФОТО: ... -->`.

| Файл | Де використовується |
|---|---|
| `assets/icons/logo.svg` | Логотип у хедері |
| `assets/icons/logo_white.svg` | Логотип у футері |
| `assets/icons/shield.svg`, `calendar.svg`, `wheel.svg` | Іконки блоку «Оренда без дрібного шрифту» |
| `assets/images/home/hero-bg.jpg` | Фон Hero (шлях — у `css/pages/home.css`) |
| `assets/images/about/about.jpg` | Фото на сторінці «Про нас» |
| `assets/images/cars/<slug>.jpg` | Фото авто: картка на головній, у каталозі та на сторінці авто |

`<slug>` — це назва сторінки авто без `.html`, наприклад `assets/images/cars/mercedes-benz-c140.jpg`.

Ваші старі файли достатньо перейменувати: `1967mustang.jpg` → `ford-mustang-1967.jpg`, `mercedes_benz_w111.jpg` → `mercedes-benz-220se.jpg`, `mercedes_c140.jpg` → `mercedes-benz-c140.jpg`, `hero_bg.jpg` → `home/hero-bg.jpg`.

## Як це працює

### Хедер
- На екранах ≤ 768px три пункти ховаються в кнопку **«Меню»** з випадним списком (закривається кліком поза меню, Esc або після вибору пункту).
- При наведенні з’являється підкреслення кольору самого пункту (`background: currentColor`).
- Хедер «липкий» — залишається зверху при скролі.
- **Кнопка «Бронювати»** — звичайне посилання-якір, тому куди вона веде, задається в `href`:

  | Сторінка | `href` | Що відбувається |
  |---|---|---|
  | Головна | `#cars` | плавний скрол до «Обери своє ретро» |
  | Каталог | `#fleet` | скрол до сітки авто |
  | Про нас | `cars.html` | перехід у каталог |
  | Сторінка авто | `#booking` | скрол до форми бронювання |

  Щоб змінити місце, куди скролить кнопка: додайте потрібному блоку `id="щось"` і поставте в кнопці `href="#щось"`.

### Кнопки (референс із Figma)
Клас `.btn--primary` має всі 6 станів: звичайний → hover (royal) → після кліку (помаранчева рамка, клас `.is-pressed`) → натиснута (майже чорна) → `disabled` (сіра) → `.is-loading` (спінер).
Кнопки на картках авто — `.btn--swap`: «ОБРАТИ АВТО» при наведенні змінюється на «ПЕРЕЙТИ».
Кнопка в Hero (`.btn--hero`) навмисно має окремий стиль, без референсу.

### Каталог
Фільтр працює через атрибути: кнопка `data-filter="wedding"` показує картки з `data-category="wedding"`. Можна давати посилання одразу на категорію: `pages/cars.html?category=photo`.

### Сторінка авто
- Ціна за добу береться з `data-price` у тегу `<form class="booking">`, назва авто — з `data-car`.
- Календар: поточний місяць, стрілки ‹ › для перемикання, минулі дні недоступні, дата повернення — щонайменше наступного дня після отримання.
- Підсумок рахується автоматично (`ціна × кількість діб`).
- «Забронювати» → спінер ~1 с → модалка «Бронювання підтверджено!». Справжнього бекенду поки немає: місце під запит позначене `TODO` в `js/booking.js`.

## Як додати нове авто
1. Скопіюйте будь-який файл з `pages/cars/`, перейменуйте (`porsche-911-1973.html`).
2. Замініть назву, тег, `data-price`, `data-car`, характеристики й опис.
3. Додайте картку в `pages/cars.html` (скопіюйте сусідню `<article class="car-card ...">`, змініть посилання, `data-category` і текст).
4. Покладіть фото в `assets/images/cars/porsche-911-1973.jpg`.
