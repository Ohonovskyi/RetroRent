# RetroRent — фронтенд

Сайт оренди ретро-автомобілів: HTML + **Tailwind CSS** (готовий файл `css/tailwind.css`) + трохи власного CSS і чистого JavaScript. Без npm: Tailwind перезбирається службовою сторінкою `tools/tailwind-build.html`.

## Як запустити

Відкрити через VS Code → **Live Server** (або опублікований сайт на Netlify / Vercel).
Потрібен інтернет: шрифти й плагіни (Swiper, Fancybox, Typed.js) підтягуються з CDN.

> Калькулятор оренди завантажує `data/data.json` через `fetch`. Якщо відкрити `index.html` подвійним кліком (`file://`), браузер заблокує запит і калькулятор покаже «Не вдалося завантажити список авто». Решта сайту працює й так.

## Як підключено Tailwind

У `<head>` кожної сторінки:

```html
<link rel="stylesheet" href="css/style.css">      <!-- власні стилі -->
<link rel="stylesheet" href="css/tailwind.css">   <!-- Tailwind: лише класи, які є в проєкті -->
```

У HTML доступні кольори бренду як звичайні класи Tailwind: `bg-navy`, `text-royal`, `bg-cream`, `text-brand-green`, `font-head`, `shadow-card` тощо. Тема — `js/tailwind.config.js`.

До ЛР №12 Tailwind підключався через Play CDN (`cdn.tailwindcss.com`): 124 KB JavaScript, який на кожному завантаженні збирав CSS просто в браузері й блокував відображення сторінки. Тепер CSS зібраний заздалегідь (37 KB, ~7 KB у gzip).

**Додали новий клас у HTML чи JS — перезберіть CSS:**
1. Відкрийте `tools/tailwind-build.html` через Live Server.
2. «Згенерувати» → «Завантажити tailwind.css» → замініть файл `css/tailwind.css`.

Новий HTML- чи JS-файл допишіть у масив `FILES` на цій сторінці. Якщо встановлено Node.js: `npx tailwindcss@3.4.17 -c tailwind.config.cjs -o css/tailwind.css --minify`.

## Головна сторінка — лендинг

Сторінка складається з трьох блоків (якорі в дужках):

1. **Світлий:** Переваги з вікнами при наведенні (`#benefits`), Послуги (`#services`)
2. **Темний:** Обери своє ретро (`#cars`), Відео (`#video`)
3. **Світлий:** Калькулятор оренди (`#calculator`), Як це працює (`#how`), Часті запитання (`#faq`), заклик до дії, Форма зв'язку (`#feedback`), Контакти й карта (`#contacts`)

- **Відео YouTube:** в `index.html` знайдіть `VIDEO_ID` і замініть на ID свого відео (YouTube → «Поділитися» → «Вбудувати», частина адреси після `/embed/`).
- **Карта:** адреса задана в `src` iframe карти (`q=Rynok+Square,+Lviv`) і в посиланні «Прокласти маршрут».
- Розміри, радіус і тінь відео та карти — змінні `--embed-*` у `:root` файлу `css/style.css`.
- Вікна на картках переваг відкриваються при наведенні та з клавіатури (Tab). На телефонах наведення немає, тому подробиці видно одразу (клас `.benefit` у `css/style.css`).

## Темна тема

- Перемикач (місяць/сонце) у хедері поруч із «Бронювати» на всіх сторінках. На телефонах до 640 px він у меню «Меню».
- Вибір зберігається в `localStorage` (`retrorent-theme`). Якщо користувач ще не обирав, береться тема системи.
- Початкову тему ставить короткий inline-скрипт у `<head>` кожної сторінки, тому сторінка відкривається одразу в потрібній темі, без спалаху. `js/theme.js` (з `defer`) відповідає за перемикач і збереження.
- Кольори темної теми — змінні `--d-*` у розділі «9. Темна тема» файлу `css/style.css`. Правила перефарбовують ті самі класи Tailwind, що й у світлій темі. Кнопки з класом `keep-light` лишаються білими.

## Плагіни (ЛР №10)

Підключені через CDN jsDelivr лише на головній, налаштування — `js/plugins.js`. Typed.js завантажується з `defer`. Swiper і Fancybox (CSS + JS) `plugins.js` підвантажує лише тоді, коли слайдер чи галерея наближаються до екрана (IntersectionObserver), тож вони не гальмують перше відображення.

| Плагін | Де | Що робить |
|---|---|---|
| Swiper.js 11 | «Обери своє ретро» (`.cars-swiper`) | Слайдер 9 авто: автопрокрутка 3,5 с із паузою при наведенні, стрілки, пагінація, клавіатура, 1/2/3 картки на 320/768/1024 px |
| Fancybox 5 | «Галерея» (`data-fancybox="retro-gallery"`) | Фото відкриваються одним альбомом: fade-перехід, наближення до 3×, свайпи на телефоні |
| Typed.js 2 | Hero (`#typed-text`) | Друкує сценарії оренди по колу |

Якщо в системі ввімкнено «зменшити рух», автопрокрутка й анімація друку вимикаються.

## Калькулятор оренди (ЛР №11)

Секція `#calculator` на головній. Логіка — `js/widget.js`, дані — `data/data.json`.

- **Параметри:** авто (select), кількість діб (number, 1–30), пробіг (range, 0–3000 км), водій і весільний декор (checkbox), промокод (текст).
- **Формула:** ціна × діб − 10 % від 7 діб + водій 50 $/доба + 0,5 $ за кожен км понад 200 км/доба + декор 40 $, далі знижка промокоду. Підсумок округлюється до цілого долара.
- Перераховується одразу на подіях `input` / `change`. Помилки показуються під полем (червона рамка, `aria-invalid`), а замість суми — «—». NaN, Infinity чи від’ємна сума на екран не потрапляють.
- Дробові доби округлюються вгору (2,5 → 3) з підказкою під полем.
- Ціни, межі полів і промокоди змінюються лише в `data/data.json`, код правити не треба.
- Код ізольований в IIFE, без глобальних змінних. JS шукає елементи за `data-rc` всередині свого `[data-rent-calc]`.

## Сторінка авто

- **Ціни й страхування:** масив `INSURANCE` і константа `DRIVER_PRICE` на початку `js/booking.js`. Кожен рівень задає надбавку у відсотках, франшизу й заставу (у добових ставках авто).
- **Гривні:** курс береться з API НБУ. Якщо запит не вдався, працює `FALLBACK_RATE` з підписом «Орієнтовний курс».
- **Хто за кермом:** `data-default-mode="self"` або `"driver"` у тегу `<form>` задає варіант за замовчуванням.
- **Перевірка посвідчення (`js/license.js`):** потрібна для варіанта «Самостійно». Умови (`MIN_AGE`, `MIN_EXPERIENCE_YEARS`) на початку файлу. Перевіряються лише формат і умови оренди, дані не надсилаються й не зберігаються.
- **Контакти:** ім'я й телефон обов'язкові для бронювання, перевірка в `js/booking.js`, поле телефону — `js/phone-input.js` (див. нижче). Номер показується у вікні підтвердження як `+380 97 123 45 67`.
- **З водієм:** блок перевірки посвідчення й пункт «Категорія B · Посвідчення» в характеристиках (`data-self-only`) ховаються — посвідчення клієнта не потрібне.
- **Галерея (`js/gallery.js`):** велике фото + 4 мініатюри. Додаткові фото кладіть у `assets/images/cars/<назва-сторінки>/` з іменами `1.webp` … `4.webp`. Поки файлу немає, показується сірий плейсхолдер.

## Форма зворотного зв'язку

Секція `#feedback` в `index.html`, логіка — `js/validation.js`. Поля: `username`, `email`, `phone`, `topic` (необов'язкове), `message`, `agreement`.

| Поле | Правило |
|---|---|
| Ім'я | щонайменше 2 символи, лише літери, пробіл, апостроф, дефіс |
| Email | формат `name@domain.com` |
| Телефон | код країни зі списку + точна кількість цифр для країни; для України рівно `+380` і 9 цифр (`/^\+380\d{9}$/`) |
| Повідомлення | від 10 до 500 символів |
| Згода | обов'язково відмічена |

Помилки з'являються лише після виходу з поля або натискання «Надіслати».

### Поле телефону (`js/phone-input.js`)

- Ліворуч список країн, за замовчуванням Україна **+380**. Користувач вводить лише свій номер: `97 123 45 67`.
- Цифри групуються пробілами під час введення; літери й символи не вводяться; нуль на початку (`097…`) прибирається сам.
- Вставили номер повністю (`+48 512 345 678`, `380971234567`) — країна визначається автоматично.
- Довжину номера для кожної країни перевіряє `PhoneInput.validate(input)`; міжнародний формат для сервера — `PhoneInput.getNumber(input).e164` (`+380971234567`).
- Країни, приклади й групування — масив `COUNTRIES` на початку файлу.

Бекенду немає: дані нікуди не надсилаються, форма показує демонстраційне модальне вікно. Місце під реальний запит позначене коментарем у `js/validation.js`.

## Адаптивність (mobile first)

Класи без префікса — для телефона, `sm:` (≥640px), `md:` (≥768px), `lg:` (≥1024px), `xl:` (≥1280px) — для ширших екранів.

| Елемент | Mobile | Tablet | Desktop |
|---|---|---|---|
| Меню | кнопка «Меню» (`md:hidden`) | пункти в рядок (`hidden md:flex`) | те саме |
| Сітка карток | `grid-cols-1` | `sm:grid-cols-2` | `lg:grid-cols-3` |
| Footer | 1 колонка | `md:grid-cols-2` | `lg:grid-cols-4` |
| Сторінка авто | фото → бронювання → опис | те саме | `lg:grid-cols-5`: фото й опис зліва, бронювання справа |

## Кнопки (референс Figma)

Усі стани зроблені варіантами Tailwind: `hover:bg-royal`, `active:bg-ink active:scale-98`, `focus-visible:ring-3 focus-visible:ring-brand-orange`, `disabled:bg-disabled`.
Два стани вмикає JavaScript (вони в `css/style.css`): `.is-pressed` — помаранчева рамка після кліку, `.is-loading` — спінер.
Кнопки на картках: `group` + `group-hover:` міняють «ОБРАТИ АВТО» на «ПЕРЕЙТИ».

## ЛР №12: аудит, оптимізація, CI/CD

- **Lighthouse (mobile) до оптимізації:** Performance 82, Accessibility 94, Best Practices 100, SEO 100.
- **Performance:** Tailwind CDN → готовий `css/tailwind.css`; фото JPG → WebP (11,1 MB → 4,6 MB); preload фону Hero з `fetchpriority="high"`; Swiper і Fancybox завантажуються за потреби; скрипти з `defer`; тема — inline-скриптом.
- **Accessibility:** колір `brand-green` затемнено до контрасту 5,2:1 (WCAG AA); крапки пагінації слайдера 12 px з кроком 24 px, стрілки 48×48 px.
- **SEO / Best Practices:** фавіконка, `canonical`, Open Graph, `robots.txt`, `sitemap.xml`, `rel="noopener noreferrer"`, заголовки безпеки у `vercel.json` / `_headers`.
- **CI/CD:** `.github/workflows/deploy.yml`. Кожен push у `main` запускає `scripts/check_site.py`, потім деплой на Vercel. Потрібні секрети репозиторію `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID` (без них деплой пропускається з попередженням).
- Домен `https://retrorent.vercel.app` вказаний у `canonical`, Open Graph, `robots.txt` і `sitemap.xml` — якщо сайт на іншій адресі, замініть.

## Як додати нове авто
1. Скопіювати будь-який файл з `pages/cars/`, перейменувати.
2. Замінити назву, тег, `data-price`, `data-car`, характеристики й опис.
3. Додати картку в `pages/cars.html` (скопіювати сусідню `<article>`, змінити посилання, `data-category`, текст).
4. Покласти фото в `assets/images/cars/` і вказати шлях у `src`.
5. Додати авто в масив `cars` у `data/data.json`, щоб воно з’явилося в калькуляторі оренди.
